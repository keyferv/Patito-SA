## Demo multimodal de imágenes

Para probar el análisis multimodal, abrí Streamlit, bajá hasta el expander "Análisis multimodal de imágenes" y subí una imagen de prueba. Una captura de pantalla que muestre un error 503 en un sistema de facturación es un buen caso de demo. El contenido sugerido de la imagen es:

- Una ventana de navegador con el texto "Error 503 — Servicio no disponible".
- O una pantalla de sistema con un mensaje de error visible.

El análisis esperado debe describir lo que se observa en la imagen y mencionar si parece estar relacionada con un caso de soporte TI, sin afirmar diagnósticos si la imagen no es clara.
